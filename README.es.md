# Everend Spec

<a href="README.md">English</a>

Contratos de formatos portables que conectan las herramientas Everend Forge: bóvedas Markdown, grafos ramificados, paquetes runtime e informes de validación.

## Empieza aquí

- [Contrato principal v0.1](SPEC-V0.1.md)
- [Contrato v0.2](SPEC-V0.2.md)
- [Formato de bóveda](docs/vault-format.md)
- [Paquetes runtime](docs/runtime-package.md)
- [Informes de validación](docs/validation-report.md)
- [Esquemas y ejemplos](schemas/)

La especificación permite que cada aplicación evolucione por separado y conserve interoperabilidad mediante identificadores estables y estructuras versionadas.

## Validación

~~~sh
npm install
npm test
~~~
